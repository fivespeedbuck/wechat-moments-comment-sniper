# 朋友圈抢车大王 V3（F7 停止版）

一个面向 Windows 微信桌面版的半自动朋友圈新内容检测与评论辅助工具。

## 主要功能

- F8 跨窗口获取刷新点、检测区域及按钮位置。
- 使用检测区域截图判断朋友圈内容变化。
- 使用模板匹配定位动态位置的“…”按钮。
- 自动打开评论菜单、粘贴文本并点击绿色发送按钮。
- F7 随时停止当前任务。
- Pillow 不可用时可回退到 Windows 原生截图。

## 环境要求

- Windows 10/11
- Python 3.10 或更高版本
- 微信 Windows 桌面版

## 从源码运行

```powershell
py -m pip install -r requirements.txt
run\start_moments_comment_sniper.bat
```

也可以直接运行：

```powershell
py src\moments_comment_sniper.py
```

## 打包 EXE

双击 `build_windows.bat`。生成文件位于 `dist` 目录。

## 使用提示

1. 微信窗口位置、大小或系统显示缩放改变后，需要重新校准。
2. 检测区域应覆盖新内容以及右侧“…”按钮。
3. 正式运行前先用测试内容核对评论菜单和发送按钮位置。
4. F7 是紧急停止键。

## 注意

本项目仅用于个人设备上的界面自动化学习与测试。自动操作可能误触、误发，也可能受到微信版本更新影响；请仅操作自己的账号并遵守平台规则。
